`geospec run` and `geospec check` run spec files in worker processes by default: one per CPU core but one, never more than the selected files, each with its own engine and one execution permit; a `--bail` run defaults to one. `--workers <n>` sets the count and `--workers 1` runs one process. Reports keep declared file order, so a run's report is the same for any worker count; only `durationMs` and each run's load-id nonce differ, as they do between any two runs, and memory grows with one Node and OCCT working set per process. `createGeoSpecNodePoolRunner` gains `isolation: 'process'`, which forks one process per worker; its default stays `'thread'`. `createNodeGeoSpecCliHost` gains `isolation`, which defaults to `'process'`.
