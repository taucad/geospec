Check BRep validity per solid in parallel under an execution grant. A native engine with two or more execution permits checks a STEP compound of independent solids one solid at a time on up to four threads, whatever the number of permits. Each distinct solid definition gets its own analyzer with the analyzer's own parallel mode off, and the first failing solid in the shape's order decides, as on one thread. A shape the split cannot divide, a set of solids in which one holds more than a quarter of the faces, and the whole-shape check after a failing solid stay on the calling thread.

One permit, the default, is unchanged, and fewer than four solids always run serially. Validity facts and their reasons, `maxTolerance`, `invalidSolidCount`, verdicts, refusals and charged work units are the bytes one permit produces. Memory grows with one analyzer working set per thread.
