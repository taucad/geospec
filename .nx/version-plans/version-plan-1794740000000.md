A warm `geospec run` no longer parses a STEP file whose claims are all answered from the facts store. The `geospec-facts-v1` family keeps one admission record per STEP source, keyed by its bytes' SHA-256 and length, the connector profile and the builds: the length unit, the occurrence count, surfaceless faces and schema gaps OCCT read. A z-up load with a stored record takes its subject identity from it, keeps a copy of the bytes and opens the document only when a claim needs the shape. Reports are byte-identical to a run without a store apart from `durationMs`, the per-run `loadId` nonce and `bundleSha256`.

Loading a model no longer compares its bytes with each retained model one byte at a time through a callback, which cost about 330 ms per load of a 31 MB file. On the 313-file Mac pairing set on Linux with three workers, a warm run takes 7.6 s against 42.5 s before both changes.

The bin keeps each project's file durations beside the facts store and starts the files that took longest first, so one long model no longer runs alone at the end of a run. `createGeoSpecNodePoolRunner` takes the table as `timings` and never splits a file across workers with it. Nothing is recorded with `GEOSPEC_FACTS_STORE=off`, and the order changes nothing in the report.

`defaultGeoSpecSubjectRetention` keeps 64 models per worker instead of 24, and a retaining worker raises its engine's `maxRetainedSubjects` to make room for them. `createNodeGeoSpecEngine` takes `limits` for the native addon. A kept model whose facts were measured holds its parsed document, about two to five times its file size.

`toBeValidBrep` on a STEP compound of separate solids analyzes each solid at most once. Before, a compound with an invalid solid was analyzed up to three times: by solid definition, by placed solid, then as a whole to count the invalid solids. The count now comes from the placed solids themselves. On "2277 RGB Matrix" (57 MB, one invalid solid of 57) the validity test took 29.9 s against 89.4 s on Linux. Validity facts, reasons, `invalidSolidCount`, verdicts and refusals are unchanged on the 415-file union set at one, two and four permits.
