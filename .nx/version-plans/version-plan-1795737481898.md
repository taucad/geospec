The facts store publishes each fact without taking the store lock and without syncing it. A fact is now one record file, written to a temporary name and linked into place, so a first run with an empty store costs about what a run with the store off costs, rather than six synced files and directories per fact under one lock that every worker shares. Publications no longer wait for other workers, so none is dropped after a lock wait, and a run leaves a complete store for the next one.

Each stored fact is still checked on every read (its key, length and SHA-256), so a record a power loss leaves short or empty is a miss, recomputed and then replaced, never served. A fact survives any process exit at once and a power loss once the operating system has written it back. Two different results for one fact still mark it divergent, and it is never served again.

The store keeps its size limits by reserving room in chunks of up to 128 facts and 2 MiB, so with several workers it can exceed its limits by one chunk per worker until the next eviction. Eviction now deletes the oldest entries down to the low-water mark in one pass. The layout moves to `managed-v4` inside the store directory. Stores written by earlier versions are left where they are and not read; a directory named in `GEOSPEC_FACTS_STORE` or restored from a CI cache keeps its `managed-v3` folder until it is removed by hand.
