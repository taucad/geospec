These assertions check whether the geometry is sound enough for other measurements: how many pieces it has, whether it is closed, and what its loader reported.

The Python examples run inside this block. `gear` and `box` are the site's demo models; `tessellated` is the engine fixture `read-profile/box-tessellated-only.step`; `triangle` is one open triangle in `mesh-buffer-v1`, admitted through `ingest_mesh`; `y_up_plate` is the demo plate admitted in a y-up frame through `ingest_subject`.

```python title="test_mesh.py"
import struct
from pathlib import Path

from geospec import GeoSpecEngine, expect_geo, load_model

# mesh-buffer-v1: "GSM1", u32 vertex and triangle counts, f64 coordinates, u32 indices.
triangle_bytes = b"GSM1" + struct.pack("<II9d3I", 3, 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 1, 2)

with GeoSpecEngine(model_root=".") as engine:
    gear = load_model(file="involute-gear.glb", source_unit="mm")
    box = load_model(file="box-10x20x30.step", format="step")
    tessellated = load_model(file="fixtures/read-profile/box-tessellated-only.step", format="step")
    triangle = engine.ingest_mesh(triangle_bytes)
    y_up_plate = engine.ingest_subject(
        Path("plate-with-through-bore.step").read_bytes(),
        format="step", coordinate_system="y-up", source_unit="auto", output_unit="mm",
        ingest_options={"name": "part"},
    )
```

## toHaveConnectedComponents

Asserts how many separate pieces of material the subject has.

**Signature**

```ts
capability: 'toHaveConnectedComponents'
payload: { kind: 'connectedComponents', expected: { count, toleranceMm?, tolerance? } }
// Python: expect_geo(part).to_have_connected_components(count=..., toleranceMm=...)
// Inside Tau: expectGeo(part).toHaveConnectedComponents(expected)
```

**Payload**

| Field         | Type               | Default     |
| ------------- | ------------------ | ----------- |
| `count`       | integer, 0 or more | required    |
| `toleranceMm` | number, 0 or more  | `tolerance` |
| `tolerance`   | number, 0 or more  | `0.02`      |

Pieces closer than `toleranceMm` count as one component. When both are given, `toleranceMm` wins. Wire: `{ kind: 'connectedComponents', expected }`.

**Admitted geometry**

- STEP: clusters of BRep bodies.
- Mesh and glTF/GLB: closed material shells. Every edge must be shared by exactly two oppositely directed triangles; an open or inconsistently oriented mesh refuses rather than being counted.
- Touching that only looks connected in a render is not connectivity, and does not justify a larger tolerance.

**Refusal codes**

- `GEOSPEC_INVALID_EVIDENCE`: the mesh is not made of closed, consistently oriented shells.

A failed claim carries `GEOSPEC_CONNECTED_COMPONENTS_MISMATCH`.

**Examples**

```ts title="TypeScript"
[
  // passed: gear, the ten-tooth gear, a GLB mesh
  {
    claimId: 'pieces',
    capability: 'toHaveConnectedComponents',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'connectedComponents', expected: { count: 1 } },
  },
  // refused (GEOSPEC_INVALID_EVIDENCE): triangle, one open triangle in mesh-buffer-v1
  {
    claimId: 'pieces-open',
    capability: 'toHaveConnectedComponents',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'connectedComponents', expected: { count: 1 } },
  },
];
// Inside Tau: expectGeo(part).toHaveConnectedComponents({ count: 1 })
```

```python title="Python"
expect_geo(gear).to_have_connected_components(count=1)  # passed
expect_geo(triangle).to_have_connected_components(count=1)  # refused (GEOSPEC_INVALID_EVIDENCE)
```

## toBeWatertight

Asserts that the subject's surface is closed: every edge borders exactly two faces.

**Signature**

```ts
capability: 'toBeWatertight'
payload: { kind: 'watertight', expected: true }
// Python: expect_geo(part).to_be_watertight()
// Inside Tau: expectGeo(part).toBeWatertight()
```

**Payload**

None. Wire: `{ kind: 'watertight', expected: true }`; `expected` may be omitted.

**Admitted geometry**

- STEP: edge incidence in the exact BRep topology. A BRep subject is never tessellated for this claim.
- Mesh and glTF/GLB: edge incidence in the triangles. The open triangle fails with three open edges.
- The claim checks closure only. It does not establish manifold validity, fusion or material connectivity, and bounds establish none of these.

**Refusal codes**

The common refusals only. A failed claim carries `GEOSPEC_WATERTIGHT_MISMATCH`, with the counts of open and non-manifold edges.

**Examples**

```ts title="TypeScript"
[
  // passed: gear, the ten-tooth gear, a GLB mesh
  {
    claimId: 'closed',
    capability: 'toBeWatertight',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'watertight', expected: true },
  },
  // refused (GEOSPEC_EVIDENCE_UNSUPPORTED): tessellated, a STEP box whose faces carry no surface
  {
    claimId: 'closed-tessellated',
    capability: 'toBeWatertight',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'watertight', expected: true },
  },
];
// Inside Tau: expectGeo(part).toBeWatertight()
```

```python title="Python"
expect_geo(gear).to_be_watertight()  # passed
expect_geo(tessellated).to_be_watertight()  # refused (GEOSPEC_EVIDENCE_UNSUPPORTED)
```

## toHaveMeshIntegrity

Asserts that the mesh evidence is sound enough for the checks that follow it.

**Signature**

```ts
capability: 'toHaveMeshIntegrity'
payload: { kind: 'meshIntegrity', expected: { finitePositions?, degenerateTriangles?, duplicateFaces?, watertight?, triangleCount? } }
// Python: expect_geo(part).to_have_mesh_integrity(finitePositions=..., triangleCount=...)
// Inside Tau: expectGeo(part).toHaveMeshIntegrity(expected)
```

**Payload**

| Field                 | Type                                    | Default     |
| --------------------- | --------------------------------------- | ----------- |
| `finitePositions`     | boolean                                 | not checked |
| `degenerateTriangles` | `{ count?, maxCount?, areaTolerance? }` | not checked |
| `duplicateFaces`      | `{ count?, maxCount? }`                 | not checked |
| `watertight`          | boolean                                 | not checked |
| `triangleCount`       | numeric expectation                     | not checked |

Only declared fields are checked. `areaTolerance` counts only degenerate triangles whose area is at most that value. Wire: `{ kind: 'meshIntegrity', expected }`.

**Admitted geometry**

- Mesh and glTF/GLB: every field.
- STEP: `watertight` only, answered from the exact BRep topology. The other fields would measure a tessellation GeoSpec made, not the subject, so a STEP claim that declares them refuses.

**Refusal codes**

- `GEOSPEC_UNSUPPORTED_EVIDENCE`: a STEP claim declares a field other than `watertight`.

A failed claim carries `GEOSPEC_MESH_INTEGRITY_MISMATCH`.

**Examples**

```ts title="TypeScript"
[
  // passed: gear, the ten-tooth gear, a GLB mesh of 624 triangles
  {
    claimId: 'integrity',
    capability: 'toHaveMeshIntegrity',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: {
      kind: 'meshIntegrity',
      expected: { finitePositions: true, duplicateFaces: { count: 0 }, triangleCount: 624 },
    },
  },
  // refused (GEOSPEC_UNSUPPORTED_EVIDENCE): box, the 10 × 20 × 30 mm STEP box
  {
    claimId: 'integrity-step',
    capability: 'toHaveMeshIntegrity',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'meshIntegrity', expected: { finitePositions: true } },
  },
];
// Inside Tau: expectGeo(part).toHaveMeshIntegrity({ finitePositions: true, duplicateFaces: { count: 0 }, triangleCount: 624 })
```

```python title="Python"
expect_geo(gear).to_have_mesh_integrity(finitePositions=True, duplicateFaces={"count": 0}, triangleCount=624)  # passed
expect_geo(box).to_have_mesh_integrity(finitePositions=True)  # refused (GEOSPEC_UNSUPPORTED_EVIDENCE)
```

## toHaveNoDiagnostics

Asserts that the subject was admitted without diagnostics at the rejected severities.

**Signature**

```ts
capability: 'toHaveNoDiagnostics'
payload: { kind: 'noDiagnostics', expected: { severities? } }
// Python: expect_geo(part).to_have_no_diagnostics(severities=[...])
// Inside Tau: expectGeo(part).toHaveNoDiagnostics(expected)
```

**Payload**

| Field        | Type                                      | Default                |
| ------------ | ----------------------------------------- | ---------------------- |
| `severities` | array of `'error'`, `'warning'`, `'info'` | `['error', 'warning']` |

Wire: `{ kind: 'noDiagnostics', expected }`; an empty `expected` applies the default.

**Admitted geometry**

- Any admitted subject in a z-up frame. The claim reads the diagnostics the host attached when it ingested the subject; it measures no geometry, so a STEP box whose faces carry no surface still answers.

**Refusal codes**

The common refusals only. A failed claim carries `GEOSPEC_DIAGNOSTICS_PRESENT`, listing each rejected diagnostic.

**Examples**

```ts title="TypeScript"
[
  // passed: gear, the ten-tooth gear, a GLB mesh
  {
    claimId: 'clean',
    capability: 'toHaveNoDiagnostics',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'noDiagnostics', expected: {} },
  },
  // refused (GEOSPEC_UNSUPPORTED_EVIDENCE): yUpPlate, the demo plate admitted in a y-up frame
  {
    claimId: 'clean-y-up',
    capability: 'toHaveNoDiagnostics',
    subjectSlots: ['part'],
    polarity: 'positive',
    workUnitBudget: 8000000,
    payload: { kind: 'noDiagnostics', expected: {} },
  },
];
// Inside Tau: expectGeo(part).toHaveNoDiagnostics()
```

```python title="Python"
expect_geo(gear).to_have_no_diagnostics()  # passed
expect_geo(y_up_plate).to_have_no_diagnostics()  # refused (GEOSPEC_UNSUPPORTED_EVIDENCE)
```
