The `geospec-engine` wheel installs two packages: `geospec`, the assertion API this page documents, and `geospec_engine_native`, the engine itself. A GeoSpec assertion in Python is one engine call that returns the canonical plan, claim and result bytes, so a report is something to keep, not only a boolean.

## Install

```bash tab="pip"
pip install geospec-engine
```

```bash tab="uv"
uv add geospec-engine
```

Wheels ship for CPython 3.13 and 3.14 on macOS arm64 and manylinux_2_28 x86_64. The wheel registers a pytest plugin named `geospec`, active as soon as the package is installed.

## Every call and its default

```python
from geospec import GeoSpecEngine, expect_geo, load_model

engine = GeoSpecEngine(
    model_root=".",          # default None: load_model(file=...) refuses until a root is set
    work_unit_budget=None,   # default: the engine's 8_000_000
    execution_permits=None,  # default 1; up to the host's CPU count
    cache_root=None,         # with project_root, opts into the filesystem cache
    project_root=None,
    model_loader=None,       # exports code models; required for load_model(code=...)
)

with engine:
    part = load_model(
        file="part.step",     # exactly one of file (relative to model_root) and source (bytes or path)
        format="step",        # default "glb"; also "gltf", "stp"
        source_unit="auto",   # default "auto" for STEP, "m" otherwise; a millimetre GLB needs "mm"
        resources=(),         # glTF buffers: [{"name": ..., "source": bytes | path}]
        ingest_options=None,  # STEP {"name": ...}; default {}
        name="part.step",     # the primary's name in the report's provenance; default: the file name
    )
    report = expect_geo(part, claim_id="size").to_have_bounding_box(size={"x": 40, "y": 40, "z": 20})
```

## `GeoSpecEngine`

One engine owns its subjects and runs on the thread that created it. It is a context manager: entering it makes it the active engine for `load_model`, and leaving it closes it and releases every subject.

```python
import struct
from geospec import GeoSpecEngine, evaluate_geo

mesh_bytes = b"GSM1" + struct.pack("<II9d3I", 3, 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0, 1, 2)  # one triangle
with GeoSpecEngine(model_root=".") as engine:
    print(engine.protocol_version, engine.registry_version, engine.canonical_profile)
    print(len(engine.capabilities), engine.configuration["defaultWorkUnitBudget"])
    plate = engine.ingest_subject(
        open("plate-with-through-bore.step", "rb").read(),
        format="step", coordinate_system="z-up", source_unit="auto", output_unit="mm",
        ingest_options={"name": "part"}, slot="part",
    )
    print(plate.slot, plate.identity_field, plate.identity[:16])
    with engine.ingest_mesh(mesh_bytes) as mesh:  # mesh-buffer-v1, z-up, millimetres
        print(mesh.identity_field, evaluate_geo(mesh, "toHaveBoundingBox", {"min": [0, 0, 0], "max": [1, 1, 0]}).passed)
```

```console
3 5 geospec-jcs-v1
32 8000000
part subjectHash a53548710335079b
contentHash True
```

- `ingest_subject(primary, *, format, coordinate_system, source_unit, output_unit, ingest_options=None, resources=(), slot="subject")` admits STEP, glTF or GLB bytes; `resources` is a sequence of `(name, bytes)` tuples.
- `ingest_mesh(mesh, *, slot="subject")` admits `mesh-buffer-v1` bytes and hashes them for you.
- `capabilities` is the tuple of names the engine advertised; `configuration` is the `initialize` response's configuration.
- A subject is a context manager too; `close()` releases its handle. Every subject is released when the engine closes.
- A call from another thread raises `RuntimeError`. Create the engine on the thread that uses it.

## `load_model`

`load_model(**options)` reads a model through the active engine and admits it. Exactly one of `file` and `source` is required. Paths resolve under `model_root`: an absolute path, a `..` segment, or a path that resolves outside the root is refused with `GEOSPEC_MODEL_PATH_OUTSIDE_ROOT`.

```python
from geospec import GeoSpecEngine, load_model

with GeoSpecEngine(model_root="."):
    plate = load_model(file="plate-with-through-bore.step", format="step")
    gear = load_model(file="involute-gear.glb", source_unit="mm")
    print(plate.provenance["primary"]["sha256"][:16], gear.identity_field)
```

```console
fb622c854152ce81 subjectHash
```

`format` defaults to `glb`. `source_unit` defaults to `auto` for STEP, which reads the file's own unit, and to `m` otherwise. The subject gains a frozen `provenance`: the primary's name, byte length and SHA-256, the resources and sources consumed, and the options as sent. `mesh`, `mesh_linear_tolerance`, `mesh_angular_tolerance_degrees` and `step_streaming` are refused with `GEOSPEC_MODEL_OPTION_UNSUPPORTED` on direct admission; `code=` and a `file` that is not a model format need a `model_loader`, otherwise `GEOSPEC_MODEL_HOST_UNAVAILABLE`.

## `expect_geo`

`expect_geo(subject, *, claim_id=None)` returns a matcher chain. Each matcher is the registry name in snake_case and takes one positional dict or keyword fields, never both. Field names keep their wire spelling (`toleranceMm`, `uniqueNames`). A pass returns a `GeoSpecAssertionReport`; a failure or a refusal raises `GeoSpecAssertionError`.

```python
from geospec import GeoSpecAssertionError, GeoSpecEngine, expect_geo, load_model

with GeoSpecEngine(model_root="."):
    plate = load_model(file="plate-with-through-bore.step", format="step")
    report = expect_geo(plate, claim_id="size").to_have_bounding_box(size={"x": 40, "y": 40, "z": 20})
    print(report.passed, report.result["status"], report.result["evidence"]["measured"]["size"])
    print(expect_geo(plate).to_have_bounding_box({"size": {"x": 40, "y": 40, "z": 20}}).passed)
    print(expect_geo(plate).not_.to_have_circular_hole(diameter=12).result["status"])
    try:
        expect_geo(plate).to_have_circular_hole(diameter=12)
    except GeoSpecAssertionError as error:
        print(error.code, error.result["status"], error)
    gear = load_model(file="involute-gear.glb", source_unit="mm")
    try:
        expect_geo(gear).not_.to_have_circular_hole(diameter=4)
    except GeoSpecAssertionError as error:
        print(error.code, error.result["status"])
```

```console
True passed [40, 40, 20]
True
passed
GEOSPEC_FEATURE_MISMATCH failed No circular hole matches diameter 12 within 0.02 mm.
GEOSPEC_EVIDENCE_UNSUPPORTED refused
```

`.not_` flips the polarity: the plate has no 12 mm hole, so the negated claim passes. The gear is a mesh, so a hole claim is refused, and negation leaves it refused. `to_have_bounding_box` also takes two positional vectors, `min` and `max`. A matcher name outside the registry raises `AttributeError`; a payload the engine rejects raises `GeoSpecAssertionError` with the protocol code, such as `invalid-claim`.

## `evaluate_geo` and `query_geo`

`evaluate_geo(subject, capability, *arguments, claim_id=None, polarity="positive")` runs one matcher by its registry name and returns the report whatever the status. `report.passed` is `False` for a refusal.

```python
from geospec import GeoSpecEngine, evaluate_geo, load_model, query_geo

with GeoSpecEngine(model_root="."):
    plate = load_model(file="plate-with-through-bore.step", format="step")
    gear = load_model(file="involute-gear.glb", source_unit="mm")
    report = evaluate_geo(gear, "toHaveCircularHole", {"diameter": 4})
    print(report.passed, report.result["status"], report.diagnostics[0]["code"])
    report = evaluate_geo(plate, "toHaveCircularHole", {"diameter": 12}, polarity="negative", claim_id="no-12")
    print(report.passed, report.claim["claimId"], report.claim["polarity"])
    brep = query_geo(plate, "analyzeBrep")
    print(brep.result["status"], sorted(brep.result["evidence"]))
    print(query_geo(gear, "analyzeBrep").diagnostics[0]["code"])
```

```console
False refused GEOSPEC_EVIDENCE_UNSUPPORTED
True no-12 negative
passed ['brep', 'diagnostics', 'success']
GEOSPEC_BREP_EVIDENCE_UNAVAILABLE
```

`query_geo(subject, capability, payload=None, *, claim_id=None)` runs one of `analyzeMesh`, `analyzeBrep`, `inspectGeometry`, `analyzeMeshOverlap` and `queryPmi` with its raw payload and returns the report; queries are positive only. `minimumDistance` is not callable from the facade and raises `ValueError`. A query without the evidence it reads fails rather than refuses, as the gear shows. Unlike `expect_geo`, neither function wraps a protocol error: a malformed payload raises `geospec_engine_native.ProtocolError`.

## `GeoSpecAssertionReport` and `GeoSpecAssertionError`

A report is frozen and carries the bytes a run depends on:

| Field                                                                     | Holds                                                                                                        |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `canonical_plan_bytes`, `canonical_claim_bytes`, `canonical_result_bytes` | The exact bytes the engine produced, for hashing and storing                                                 |
| `claim`                                                                   | The canonical claim as a mapping: `claimId`, `payload` with defaults filled in, `polarity`, `workUnitBudget` |
| `result`                                                                  | The result mapping: `status`, `diagnostics`, `evidence`                                                      |
| `diagnostics`                                                             | The result's diagnostics as a tuple of mappings                                                              |
| `passed`                                                                  | `True` for a passed result only                                                                              |
| `provenance`                                                              | The subject's `load_model` provenance, or `None`                                                             |

`GeoSpecAssertionError` extends `AssertionError`, so pytest reports it as a failed assertion. It adds `code` (the first diagnostic's code, or the protocol code), `report`, `result`, `claim`, `diagnostics`, the three `canonical_*_bytes` and `protocol_error`, the native exception when one was wrapped. Its message is the diagnostics' messages.

## `GeoSpecRegex`

A selector is an exact string or a `GeoSpecRegex(pattern, flags="")`, an ECMAScript pattern sent unchanged to the engine as `{"type": "regexp", "pattern", "flags"}`. A compiled `re.Pattern` is rejected with `TypeError`, because its semantics are not portable.

```python
from geospec import GeoSpecRegex, query_geo

report = query_geo(plate, "inspectGeometry", {"selectors": [{"kind": "occurrence", "name": GeoSpecRegex("^pa.*$"), "expect": "many"}]})
print(report.claim["payload"]["selectors"][0]["name"], report.diagnostics[0]["code"])
```

```console
{'flags': '', 'pattern': '^pa.*$', 'type': 'regexp'} GEOSPEC_SELECTOR_UNMATCHED
```

## The pytest plugin

Installing the wheel registers the plugin; no `conftest.py` is needed. Each test gets a lazy engine, created on the first `load_model` and closed at teardown, with `model_root` set to pytest's `rootpath`, so model paths are relative to the project root.

```python title="tests/test_plate.py"
from geospec import GeoSpecAssertionError, expect_geo, load_model
import pytest


def test_plate_size():
    plate = load_model(file="models/plate-with-through-bore.step", format="step")
    expect_geo(plate).to_have_bounding_box(size={"x": 40, "y": 40, "z": 20})


def test_plate_bore():
    plate = load_model(file="models/plate-with-through-bore.step", format="step")
    expect_geo(plate).to_have_circular_hole(diameter=10, axis="z")


def test_engine_fixture(geospec_engine):
    assert geospec_engine.registry_version == 5


def test_wrong_size_fails():
    plate = load_model(file="models/plate-with-through-bore.step", format="step")
    with pytest.raises(GeoSpecAssertionError) as raised:
        expect_geo(plate).to_have_bounding_box(size={"x": 40, "y": 40, "z": 25})
    assert raised.value.code == "GEOSPEC_BOUNDING_BOX_MISMATCH"
```

```console
$ python -m pytest tests/test_plate.py -q
....                                                                     [100%]
4 passed in 0.04s
```

A failed or refused assertion fails the test with the engine's message, here `No circular hole matches diameter 12 within 0.02 mm.` for a claim of `diameter=12`. Two fixtures are public:

- `geospec_engine_factory` returns the callable that creates the test's engine. Override it once in `conftest.py` to set a different `model_root`, a `work_unit_budget` or a `model_loader`.
- `geospec_engine` returns the engine the test's `load_model` uses.

```python title="conftest.py"
import pytest
from geospec import GeoSpecEngine


@pytest.fixture
def geospec_engine_factory(pytestconfig):
    return lambda: GeoSpecEngine(model_root=str(pytestconfig.rootpath / "models"), work_unit_budget=2_000_000)
```

## Typing

The package ships `py.typed`. `expect_geo` returns `GeoSpecMatchers`, a `Protocol` with an overload per matcher, so `to_have_volume(value=6000)` and `to_have_volume({"value": 6000})` both check and `to_have_volume(volume=1)` is rejected by mypy or pyright. Every expectation has a `TypedDict`, from `GeoSpecBoundingBoxExpectation` to `GeoSpecVoidContinuityExpectation`, plus `GeoSpecNumericExpectation` and `GeoSpecAxisExpectation`. `load_model` takes `GeoSpecLoadModelOptions`; a `model_loader` is a `GeoSpecModelLoader` returning a `GeoSpecModelArtifact`.

## The native module

`geospec_engine_native.Engine` is the engine over `bytes`, with the methods of the [TypeScript `Engine`](/docs/api#engine) in snake_case: `ingest_subject`, `ingest_mesh`, `subject_handle`, `release_subject`, `process_request`, `canonical_plan`, `evaluate_plan`, `evaluate_claim`, `observations`, `flush_cache`, `clear_overlap_cache`, `cache_producer_identity` and `close`. `canonicalize(bytes)` and `ProtocolError` sit beside it. The constructor is `Engine(cache_root=None, project_root=None, *, execution_permits=None)`, and an instance stays on its thread.

```python
import json
from pathlib import Path
from geospec_engine_native import Engine, ProtocolError, canonicalize

header = {"protocolVersion": 3, "registryVersion": 5, "canonicalProfile": "geospec-jcs-v1"}
encode = lambda value: json.dumps(value, separators=(",", ":")).encode()
engine = Engine()
step = Path("plate-with-through-bore.step").read_bytes()
admission = json.loads(engine.ingest_subject(encode({
    "method": "ingestSubject", "requestId": "ingest", **header, "format": "step",
    "frame": {"coordinateSystem": "z-up", "sourceUnit": "auto", "outputUnit": "mm"},
    "ingestOptions": {"name": "part"}, "primaryByteLength": len(step), "resources": [],
}), step, []))
subject_hash = admission["result"]["subject"]["subjectHash"]
response = json.loads(engine.process_request(encode({
    "method": "submitClaims", "requestId": "plate", **header,
    "plan": {"subjects": [{"slot": "part", "subjectHash": subject_hash}], "claims": [{
        "claimId": "size", "capability": "toHaveBoundingBox", "subjectSlots": ["part"],
        "polarity": "positive", "workUnitBudget": 8_000_000,
        "payload": {"kind": "boundingBox", "expected": {"size": {"x": 40, "y": 40, "z": 20}}},
    }]},
})))
for result in response["result"]["results"]:
    print(result["claimId"], result["status"], [d["code"] for d in result["diagnostics"]])
print(canonicalize(b'{"b": 1.50, "a": [2, 3]}'))
try:
    engine.process_request(b'{"method": ')
except ProtocolError as error:
    print(error.code, error)
engine.close()
```

```console
size passed []
b'{"a":[2,3],"b":1.5}'
invalid-json GeoSpec control input is not valid strict JSON.
```

The [API reference](/docs/api) documents every request and response; the Python facade is a thin layer over them.

## Errors

The facade raises `GeoSpecAssertionError` with these codes before any geometry is read. Codes from the engine itself are the [protocol codes](/docs/api#protocolerror) and the [diagnostic codes](/docs/reference/overview#common-refusals).

| Code                                    | Raised when                                                                                                             |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `GEOSPEC_MODEL_HOST_UNAVAILABLE`        | `load_model` without an active engine or pytest scope, without `model_root`, or for a code model without `model_loader` |
| `GEOSPEC_MODEL_PATH_OUTSIDE_ROOT`       | An absolute path, a `..` segment, or a path resolving outside `model_root`                                              |
| `GEOSPEC_MODEL_FORMAT_UNSUPPORTED`      | A `format` other than `glb`, `gltf`, `step` or `stp`                                                                    |
| `GEOSPEC_MODEL_OPTION_UNSUPPORTED`      | `mesh`, `mesh_*` or `step_streaming` on a file or bytes                                                                 |
| `GEOSPEC_MODEL_FRAME_OVERRIDE`          | `source_unit` on a code model, whose loader owns the frame                                                              |
| `GEOSPEC_MODEL_SOURCE_IDENTITY_MISSING` | A `model_loader` artefact without `consumed_sources`                                                                    |
| `GEOSPEC_MODEL_EXPORT_INTENT_MISMATCH`  | A `model_loader` artefact in another format, frame or unit than requested                                               |
| `invalid-field`                         | An unknown `load_model` option or a malformed resource                                                                  |
| `invalid-subject`                       | A subject from another engine, or a test scope that has ended                                                           |
| `invalid-response`                      | A malformed evaluation frame from the native engine                                                                     |

Plain Python errors cover the rest: `TypeError` for both `file` and `source`, positional and keyword arguments together, or an `re.Pattern`; `ValueError` for a bad `work_unit_budget`, `execution_permits` or `cache_root`, an unadvertised capability, or `minimumDistance` through `query_geo`; `RuntimeError` for a closed engine or another thread.
